# NeuX

> **您的知识火种** — 让文献与笔记在碰撞中生成珍贵结晶
---

**NeuX** 是一款**本地优先、中文友好**的知识库与文献管理工具。它汲取了 Obsidian 的双向链接、Notion 的灵活组织与 Zotero 的文献管理精髓，专为中文研究者与学生打造，让知识的积累、关联与回溯变得前所未有的简单。帮助您轻松组建个人智库。

> 正如稀有的火之珍珠由火山喷发与河流冲刷共同雕琢，您的知识库应是思考之火与时间流水淬炼出的独特结晶。

---


## ✨ 主要特点

- **🔥 本地优先，云盘同步**  
  所有数据均存储于本地，无需担心云端泄露；预计支持 WebDAV / OneDrive / 百度云等多种同步方式及云盘存储，让您完全掌控自己的知识资产。

- **🇨🇳 中文友好，开箱即用**  
  从知网/万方元数据识别到中英文混排引用格式（GB/T 7714），我们为中文环境做了大量优化，告别插件折腾。基于中文用户使用习惯开发，降低学习成本。

- **📚 集成文献管理功能**  
  PDF、BibTeX 等文献格式可直接导入，并与笔记自动建立双向链接，文献不再是孤岛。支持对文献和笔记建立同级别关键词标签，快速定位您的知识区域。

- **✍️ Markdown 笔记自由书写**  
  内置简洁的本地 Markdown 编辑器，支持实时预览、拖拽插入链接与文献引用，所见即所得，让写作专注流畅。

- **🧠 智能关联与图谱**  
  自动生成知识网络图谱，并支持手动建立文献间的关系（如“引用”“对比”），让你从宏观视角审视自己的研究。

- **⚡️ 快速检索与时间轴**  
  输入关键词即可瞬间调出所有相关文献和笔记；时间轴视图帮你回溯知识演变的轨迹，快速定位您的学习路线。

## 🧩 核心功能

| 功能                    | 描述                                                          |
| -------------------------- | ---------------------------------------------------- |
| **文献导入与元数据**     | 支持 PDF、BibTeX 导入；内置启发式规则从文件名、首页提取标题、作者、年份等，尤其适配知网、万方常见命名模式。 |
| **Markdown 编辑器**     | 所见即所得的编辑体验，支持 `[[双向链接]]` 与 `[@文献引用]` 自动补全，拖拽文献即可生成引用。       |
| **双向与反向链接**       | 在笔记中引用文献或其他笔记后，系统自动建立反向链接面板，知识关联一目了然。                       |
| **多维度组织**          | 既可以按传统文件夹归类，也能用标签、图谱和手动关系自由编织知识网络。                          |
| **图谱可视化**          | 以当前条目为中心，展示其关联的文献与笔记，支持缩放、筛选和点击跳转。                          |
| **全局搜索**           | 基于 SQLite FTS5 的全文搜索引擎，实时搜索笔记内容、文献元数据，结果高亮显示。               |
| **拖拽整理**           | 文献和笔记均可通过拖拽轻松移动、归类或建立关联，交互直觉。                               |
| **时间轴视图**          | 按时间展示所有知识条目，记录你的思考轨迹，也可手动标记重要事件。                            |

## 🚀 快速开始

> NeuX 目前处于积极开发阶段，欢迎关注或参与贡献。

### 下载与安装
- 预计支持多平台同步。（Windows / macOS / Linux / Android / iOS / HarmonyOS）。
- 敬请期待。

### 首次使用
1. 选择一个文件夹作为你的知识库根目录。
2. 将已有的 PDF 文献拖入 NeuX 窗口，系统会自动识别元数据并入库。
3. 开始创建第一篇 Markdown 笔记，用 `[[` 引用其他笔记，用 `[@` 引用文献。
4. 探索图谱、搜索和时间轴，感受知识网络的魅力。
